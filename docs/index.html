Not a panel.

A Linux panel is a strip that launches things and lists windows. Auspex keeps all of that — and is answering a different question underneath it. Here is every place it diverges from the panel you are running now.

Usually

The desktop is a backdrop

Windows sit on a fixed screen. Run out of room and you get another workspace.

Auspex

The desktop is a canvas

Windows live on a plane larger than the monitor. Pan it, zoom it, drop things in the space beyond the edge — then pan back and they are where you left them. Grid mode arranges them for you; canvas mode never touches what you placed by hand.

Usually

You type at it

A launcher, a search box, keyboard shortcuts you have to remember.

Auspex

You talk to it

whisper.cpp is compiled into the shell — not a service it calls. Say “open my downloads” and it opens. Dictate into whatever window has focus. Ask a question aloud and hear the answer back through Piper.

Usually

AI means a cloud account

An API key, a subscription, and your screen contents leaving the machine.

Auspex

The model is on your disk

Speech recognition, the language model and the voice all run locally. No key, no account, no telemetry, and it works with the network unplugged.

Usually

One tray protocol

Most panels implement StatusNotifierItem and stop there.

Auspex

Two, plus the monitor name

SNI and XApp, which is what Mint’s own applications use. Auspex also claims org.x.StatusIconMonitor — without it those applications fall back to a legacy tray and vanish from the bus entirely. On this desktop that is the difference between two icons and five.

Usually

Volume is a plugin

Sound and network arrive as panel plugins loaded into the panel’s own process.

Auspex

Volume is built in, deliberately

Those plugins publish nothing on any tray protocol, so no panel can adopt another panel’s. Auspex ships its own volume, network with a Wi-Fi list, calendar with recurring events, and a notification log built by watching the bus rather than by seizing the notification daemon.

Usually

A crash costs you the panel

Until you notice it is gone and start it again from a terminal.

Auspex

It supervises itself

Login starts a supervisor, not the shell. A crash restarts in three seconds; five crashes in five minutes is treated as a loop rather than bad luck, and it says so instead of thrashing.

Usually

The AI is a chat window

A box you paste into, next to the work rather than in it.

Auspex

A crew works in the open

Hand a task to a bench of agents that each build in their own git worktree, with an auditor reading every diff before it lands. The panel counts the subtasks off as they finish; nothing reaches your files until you accept it.

Evidence

Measured, not assumed.

Moving somebody else’s windows around means trusting what the system tells you about them. Three times it lied, and each one was found by reading real output rather than reasoning about it.

Drift

The window manager double-counted

wmctrl -lG reports a position that is neither the frame nor the client: it asks X for the client’s offset inside its frame, then translates that same offset to root coordinates. The decoration is counted twice.

asked   1920, 42 reported 1930, 100 truth    1920, 42

A 29px title bar made every window read back 58px below where it had just been put. The layout took that for a drag, wrote it in, and every window walked steadily down the screen.

Silence

A locale swallowed the calendar

Dates were built with a stream, which formats integers through the global locale. One with digit grouping writes the year with a comma — an eleven-character key that fails validation, so every event was refused without a word.

in shell  2,026-07-31 in tests  2026-07-31

Invisible to the test suite, which runs under the C locale. Seen on screen, in the corner of a popover, reading “nothing noted”.

Loop

A lost window drove a busy loop

A window parked below every monitor could never be adopted again — its centre was on no screen. So it reappeared in the adoption plan on every tick, forever.

idle, before 1 place/sec idle, after  0

A window nobody could see was quietly driving a subprocess call per managed window per second for the length of the session.

Method

How it holds together.

Auspex runs as an ordinary application inside the session you already have. It does not replace your window manager, so a crash costs you a panel rather than a desktop — and you can put the old one back with one command.

  • No Xlib anywhere in the tools. Window management goes through a seam driving wmctrl, xdotool and xprop as subprocesses, so the CLI binaries link zero X libraries and a second backend is a runtime choice rather than a rewrite.
  • The model never emits a command line. Voice commands resolve to a fixed set of verbs, executed with an argv vector through execvp. There is no shell in the path, and free text that reaches a subprocess comes from your transcript, never from a paraphrase.
  • Irreversible things are checked twice. Accepting a changeset is validated against the board that actually exists, so a number a model invented is refused rather than applied to somebody else’s work.
  • Privileged actions ask polkit. Setting the clock or the timezone goes through pkexec with the argument validated first — against the system’s own list of zones, not a pattern.
  • One engine, two faces. The crew is not reimplemented. Auspex drives the ollamadev CLI and renders the result, because two copies of that logic is how a wrong diff eventually lands in your files.

Status

Auspex runs on X11 today, on this machine, as the only panel — xfce4-panel switched off, tray intact, starting itself at login under a supervisor. A wlroots spike has already proved the part X11 cannot do: scaling a live window so that zooming out makes it genuinely smaller rather than merely narrower. That is the next thing.
